## Bootloader (GPLv2) — the key obligation

The A2 boot partition contains Altera/Terasic's **U-Boot 2013.01.01** (SPL +
U-Boot proper), built **Oct 12 2016** with Altera SoC EDS 16.0 (Sourcery
CodeBench Lite 2015.11-45 / `arm-altera-eabi-gcc 5.2.0`). Conveying this binary
triggers the GPLv2 source-provision obligation, which we satisfy under **§3(a)**
by shipping the complete corresponding source **alongside** the binary, in
`legal/source/`.

The corresponding source has two parts:

1. **U-Boot tree** — `legal/source/u-boot-socfpga-ACDS16.0.tar.gz`: Intel
   `u-boot-socfpga` at tag `ACDS16.0_REL_GSRD_PR`. Verified: its `Makefile`
   reports `VERSION=2013 PATCHLEVEL=01 SUBLEVEL=01`, matching the shipped
   binary, and it contains the Cyclone V board support
   (`board/altera/socfpga`, `include/configs/socfpga_cyclone5.h`) and the
   SPL/preloader sources. U-Boot core is GPLv2; the Altera `hwlib`/preloader
   portions carry BSD-3-Clause-style headers inline in that tree.

2. **Board handoff / BSP** — the preloader's PLL / pinmux / IOCSR / SDRAM
   parameters, generated by Altera SoC EDS from the Quartus HPS project and
   published by Terasic as part of the DE1-SoC GHRD
   (`https://www.terasic.com.tw`). Retain the GHRD you built from alongside
   this bundle for completeness.

## Linux kernel (GPLv2)

We build the kernel from the unmodified mainline `linux-6.12` source plus our
own device tree (`socfpga_cyclone5_de1_soc.dts`) and `socfpga_defconfig`.
Archive the kernel source tarball + the DTS + the `.config` next to the
shipped image so the exact kernel is reproducible. The DTS is original work in
this repository (`hps/newimage/kernel/.../socfpga_cyclone5_de1_soc.dts`).

## FPGA bitstream — redistributable (attribution required)

`soc_system.rbf` is the **compiled** FPGA programming file. Its sources were
reviewed (`fpga/hps_ghrd/`):

- **Top-level HDL** (`de1_soc_top.vhd`) is the **community** DE1-SoC GHRD,
  authored by **Sahand Kashani-Akhavan** ("from Terasic documentation"), not
  Terasic's proprietary reference design. It comes from his "SoC-FPGA Design
  Guide" (`https://github.com/sahandKashani/SoC-FPGA-Design-Guide`), released
  into the **public domain under The Unlicense** (SPDX: `Unlicense`) — so it is
  freely redistributable. The upstream license text is included at
  `fpga/hps_ghrd/LICENSE.upstream`; the author is credited there and here.
- **Altera IP**: the Qsys system (`de1_soc.qsys`) instantiates only the free
  **`altera_hps`** (Hard Processor System bridge) plus clock sources — **no
  license-required premium IP**. It builds under the free Quartus Lite edition.

Intel's Quartus/IP licenses permit **distributing the compiled programming
files (`.rbf`/`.sof`) you generate**; the restriction is on redistributing
Intel IP *source RTL / simulation models*, which this product does **not** ship
(only the compiled `.rbf`). So **shipping `soc_system.rbf` is permitted**.

Keep an Intel attribution ("Contains Intel FPGA IP — Altera HPS") and the
community-GHRD author credit. If you prefer to avoid third-party attribution
entirely, this repo also contains fully-owned designs (`fpga/countdown/`,
`fpga/minimal/`) you could ship instead.
